# VİBATHON MOBİLE DAPP Backend

Server completely act as mediatary for demo purposes.

- Aim of the project is to witness and proof generate occure inside mobile application.

clone the repo

```
git clone https://github.com/ASaidOguz/express_server
```

change branch to vibathon-server 
```
git checkout -b vibathon-server 
```

install package 
```
npm install
```

and you can run the server via 
```
node ./api/index.js
```

for mobile app routing u may need to install ngrok
